# portfolio

My personal portfolio. Designed around a Markdown file viewer — sidebar navigation, tab switching, and a raw/rendered toggle. Black and white, Space Mono for UI, Space Grotesk for content.

Built with React 19, TanStack Start, Tailwind CSS v4, deployed on Vercel.
